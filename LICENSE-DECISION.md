# License decision required

The product specification leaves the final permissive open-source license unresolved (for example MIT versus Apache-2.0). This repository therefore does not currently grant a software license.

Before the first tagged public release, maintainers must make and record that decision, add the corresponding `LICENSE` file and update source/package metadata. Apache-2.0 offers an explicit patent grant and termination language; MIT is shorter and broadly familiar. Dual `MIT OR Apache-2.0` is another common Rust ecosystem choice, but must be an explicit owner decision rather than an implementation-agent assumption.
